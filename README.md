### Introduction

This project was intended to be a simple Snake Clone in C++ for learning purposes, 
to get familiar with C++ Game Development, the Vulkan Graphics API and Game Engine Development.
[river](https://github.com/flymandi/river), the engine in question, turned out to be a wildly fun project,
but since I wanted to make it a powerful 3D engine, it felt overkill to use it with such a simple game like Snake.

So I decided I was going to go the opposite route and just write Snake in Assembly with as few libraries as possible.

I plan to expand on classic Snake with some features and/or changes compared to the original gameplay loop.
